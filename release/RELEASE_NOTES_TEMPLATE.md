# Agentic Engineering Assurance System v1.0.0

Initial public technical system record for governance, auditability, and
release integrity in AI-assisted software engineering.

## Included

- system and authority model;
- implementation record;
- assurance and evidence method;
- machine-readable public claim register;
- limitations and reassessment triggers;
- publication and security boundaries;
- independent-review package; and
- reproducible publication verification.

## Evidence boundary

This release derives from sealed private baseline
`PTE-2026-08-19-v1.0.1`. Only the baseline manifest's SHA-256 commitment is
public. The underlying evidence remains private and available only through
controlled review.

## Assurance status

Evidence-backed public system record. External independent review and DOI
status must be stated here exactly as they stand at release time.

## Verification

Verify the release bundle with the attached `SHA256SUMS` and the GitHub artifact
attestation. Confirm that the release tag and commit display a verified
signature and that GitHub identifies the release as immutable.
